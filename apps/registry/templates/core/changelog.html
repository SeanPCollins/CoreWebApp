v0.1.0 — Architecture & Shell Foundation

Current Build

Released: October 2026

  • Blank Slate Refactoring: Completely stripped legacy EDiT endocrine database queries, model dependencies, and CSV import logic in favor of a clean CORE registry foundation.
  • Visual Identity Overhaul: Re-designed global aesthetics around a modern Slate & Teal palette, high-contrast dark navbar, and low-strain off-white workspace.
  • Dynamic Subpath Routing: Environment-aware URL routing via BASE_APP_URL supporting dynamic deployment (e.g., /core-dev/) across Gunicorn and Nginx reverse proxies.
  • Authentication Pipeline: User registration, tokenized email activation workflow, and real-time AJAX username/email availability checking API.
  • Interactive Shell Skeleton: Standardized multi-page base template (core/base.html) with user-aware navigation and placeholder views for upcoming chemical data models.
